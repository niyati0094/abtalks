# ABTalks — 60-Day Coding Challenge

A mobile-first frontend redesign for ABTalks, a 60-day coding challenge for Indian college students. The experience focuses the student on one clear next step: complete today's mission.

## Required routes

```
/
/dashboard
/day/12
```

The day page also supports dynamic routes such as `/day/13`.

## Included experience

- Clear challenge landing page for new students
- Student dashboard with streak, mission, progress, momentum, and achievements
- Interactive challenge flow: read → build → submit → complete
- GitHub and LinkedIn proof validation
- Completion feedback and locally persisted progress
- Responsive layout designed for a 390px mobile viewport
- Breeth memory-powered AI Coach integration

## Run locally

1. Install dependencies: `npm install`
2. Create `.env` from `.env.example` and add your Breeth key (optional for the static UI).
3. Start the app: `npm run dev`

## Build

```bash
npm run build
```
